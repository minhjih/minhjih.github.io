# 포스터/이미지 넣는 곳

이 폴더에 아래 3개 파일을 넣으면 페이지에 자동으로 표시됩니다.
(파일이 없으면 텍스트 큐시트/기본 배너로 대체됩니다.)

| 파일명            | 용도                                   | 권장 크기            |
| ----------------- | -------------------------------------- | -------------------- |
| `poster-main.jpg` | 메인 포스터 (맨 위 큰 이미지)          | 세로형, 폭 1080px+   |
| `poster-cue.jpg`  | 큐시트(타임테이블) 포스터              | 세로형, 폭 1080px+   |
| `transfer-qr.png` | 뱅킹앱 송금 QR (토스·카카오뱅크 등에서 스캔) | 정사각형 600px+ |

- 파일 이름/경로를 바꾸고 싶으면 `config.js` 의 `POSTER`, `KAKAO.qrImage` 값을 수정하세요.
- `.jpg`/`.png` 확장자를 config 값과 맞춰주세요.
